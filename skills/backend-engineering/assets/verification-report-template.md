# Verification report template

Adapt this completion report. Omit irrelevant categories and empty headings.
Use concrete commands, observations, and source links. Never turn a planned
check into an executed result.

- Implemented behavior: Describe the resulting user or system behavior.
- Decisions and assumptions: Explain consequential choices and unresolved assumptions.
- Checks executed: Record the commands or procedures, results, and observed effects.
- Performance evidence, if relevant: Record baseline, changed result, dataset, load,
  environment, and limits on the comparison.
- Documentation consulted: Link the version-relevant pages and supported decisions.
- Migration or rollout, if relevant: Describe compatibility, execution requirements,
  recovery, and any authorization still needed.
- Unverified behavior or remaining risks: Name unavailable checks, why they could
  not run, and a reproducible next step.
